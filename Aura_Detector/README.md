## The Bit

AUR/S does not measure aura, health, personality, emotion, or any real human attribute. Computer vision is used only to attach temporary visual effects to visible people. No face recognition, permanent identity, video recording, or cloud upload is in scope.

## Planned MVP

1. Android phone sends current camera frames to a local PC.
2. PC detects and tracks up to six people.
3. Phone renders auras, temporary IDs, and a selected person's fictional live `AUR/s` reading.
4. A double-tap performs a local dramatic scan, including absurd finite values and optional `±∞` outcomes.
