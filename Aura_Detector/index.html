🛠️ Build & Run Guide

Follow these instructions to set up the local Python inference server and deploy the Android client app onto a physical device.

1. PC Inference Server Setup

# Clone repository
git clone https://github.com/ARJuice/Aura_Detector.git
cd Aura_Detector/server

# Create Python virtual environment (Python 3.11 recommended)
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install PyTorch with CUDA & requirements
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt

# Launch FastAPI WebSocket server on port 8765
python app.py

2. Android Client Build & Installation

# Navigate to Android app directory
cd ../android/AuraDetector

# Build Debug APK using Gradle
gradle assembleDebug

# Streamed installation to physical Android device via ADB
adb install -r app/build/outputs/apk/debug/app-debug.apk

# Launch Main Activity
adb shell am force-stop com.auradetector
adb shell am start -n com.auradetector/.MainActivity
LAN Hotspot Recommendation

Do not use captive-portal or client-isolated public Wi-Fi. Connect both PC and Android phone to a direct 5 GHz Wi-Fi network or Windows Hotspot so the phone can reach the PC server directly without proxy redirects.

🔒 Safety, Privacy & Biometric Statement

AUR/S is explicitly a joke instrument, not a health, biometrics, or personality assessment tool.

Privacy Safeguards
  • No Biometrics / Face Recognition: Computer vision is used strictly for 2D body bounding box segmentation.
  • No Permanent Identity: Subject IDs are temporary numbers assigned per session and discarded immediately when out of frame.
  • No Recording or Cloud Upload: All image frames are processed in-memory over local Wi-Fi and immediately dropped.
