INCIDENT REPORT // 04:00 AM

OH NO.

NOT A CORPORATE "CHALLENGES" SECTION. REAL BUGS THAT ALMOST KILLED THE MAKE.

BUG #01 // HALLUCINATION FATALITY

The Sentient Cherthala Warhead

Held a plastic Bisleri water bottle in front of the camera during early vision tests. The AI returned: "Object: Soviet Nuclear Intercontinental Warhead manufactured in Cherthala, 1984. Threat Level: Catastrophic."

Verdict: Water bottle denied entry under anti-terrorism regulations.
BUG #02 // THE NEGATIVE BRIBE

The Officer Paid Me ₹50

In an early build of the immigration interrogation, typing -50 in the bribe input resulted in the officer saying: "Aha! You have taxed me! Take this ₹50 and please cross the border immediately!"

Fix: Added Math.max(0, bribe) so the government doesn't go bankrupt.
BUG #03 // PREMATURE MORTALITY

Dead Before Born

A race condition between eval-action.js and the UI renderer caused objects to trigger their death sequence while the passport animation was still sliding onto the screen.

Tragic Result: Instant obituary for a pen that never had a chance to live.
BUG #04 // SVG TEXT OVERFLOW

The 800-Word Name Disaster

Gemini decided to output a 4-paragraph psychological treatise inside the single-line Object Name field, completely obliterating the passport layout and pushing the footer into outer space.

Fix: Brutal 32-character string truncation with ellipses.

UNDER THE HOOD: THE DUAL-AI VISION ARCHITECTURE

HOW A SILLY PREMISE WAS BUILT ON SERIOUS ENGINEERING: DUAL-MODEL RACING, MULTI-FRAME CONSENSUS, AND ZERO-WIFI RESILIENCE.

PILLAR 01 // REDUNDANCY & LATENCY

Dual-AI Async Race Engine

With 100+ makers straining SCMS college WiFi, external API calls frequently spiked to 8+ seconds or threw 429 rate limits. We built an asynchronous race architecture firing Google Gemini 2.0 Flash (strong visual object detection) and NVIDIA Nemotron simultaneously. Whichever provider responds first with valid JSON wins the passport grant. Roundtrip latency plummeted to <1.2 seconds.

const winner = await Promise.race([
  callGeminiVision(frames),
  callNemotronVision(frames)
]);
PILLAR 02 // COMPUTER VISION

Multi-Frame Canvas Consensus

Holding a physical object in front of a laptop camera in dim midnight lighting produces severe motion blur. Single-shot image detection frequently hallucinated bananas as lightbulbs. Our client pipeline streams from navigator.mediaDevices into an offscreen HTML5 <canvas>, captures 3 staggered frames across 600ms, standardizes aspect ratios, and dispatches multi-frame consensus to filter jitter.

// 3-frame buffer consensus
ctx.drawImage(video, 0, 0, 320, 240);
const frames = await captureBuffer(3, 200);
PILLAR 03 // PROMPT ENGINEERING

Satirical Manglish Persona & Bribe State Machine

Generic LLM system prompts produce sterile, polite corporate assistants. We engineered strict negative constraints and few-shot Manglish examples to enforce a cynical Kerala border official persona ("mwone", "scene mone", "adichu shape maattum"). It features an interactive bribe state machine: typing a ₹50 tea charge triggers facial state transitions (stare → doubt → pass) and unlocks passage!

if (bribeAmount >= 50) {
  officer.mood = 'pass';
  return "₹50 tea charge accepted! APPROVED!";
}
PILLAR 04 // FAULT TOLERANCE

Zero-WiFi Deterministic Heuristic Fallback

At 03:30 AM, campus connectivity abruptly died. If the app crashed during judge testing, game over. We implemented generateSmartPassport(): a zero-dependency deterministic heuristic generator that hashes the object's string name into mathematical seeds to calculate unique passport IDs, existential missions, and death clocks entirely in <10ms offline.

catch (networkError) {
  // Instant 10ms offline generation
  return generateSmartPassport(objectName);
}
