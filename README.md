# Leviosa's Magical Mayhem

Build a polished, responsive web app called LEVIOSA.

LEVIOSA is a deliberately useless, funny, Harry-Potter-inspired personality quiz made for a student hackathon.

TAGLINE:

"The Sorting Hat quit. We took over."

IMPORTANT:

This is a fan-made parody project, NOT an official Harry Potter/Wizarding World product.

Do not use official Harry Potter logos, Hogwarts crests, movie screenshots, movie artwork, or copyrighted character artwork.

Use original illustrations and a Hogwarts-inspired magical aesthetic.

========================================

CORE EXPERIENCE

========================================

The final app will have:

1. Cute magical homepage

2. 10-question personality quiz

3. Character scoring system

4. Magical Sorting/loading screen

5. Character result page

6. Completely unnecessary "Hogwarts Report Card"

7. Take quiz again

8. Share result

For this first build, prioritize the COMPLETE VISUAL DESIGN and basic navigation.

Keep the architecture simple and maintainable.

========================================

IMPORTANT IMPLEMENTATION RULES

========================================

Keep the code clean and beginner-friendly.

Do not over-engineer.

Do not add unnecessary dependencies.

Do not create a backend unless absolutely necessary.

The scoring must be deterministic and happen locally.

The quiz should work without an account or login.

Make the application responsive for desktop and mobile.

Prioritize visual polish and usability.

Use subtle animations, not excessive animations.

The app should feel like a cohesive magical scrapbook from start to finish.

Most importantly:

THIS SHOULD LOOK CUTE.

The Sorting Hat should feel like the lovable mascot of the entire app.

Do not make the visual design dark, creepy, overly realistic, or serious.
