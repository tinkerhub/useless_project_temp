# Survival OS 🎯

## Basic Details

### Team Name: Survival OS

### Team Members

- Team Lead: Marlon Johnson - SCAS

### Project Description

Survival OS is a playful student dashboard for surviving college chaos. It brings attendance, assignments, money, procrastination, relationships, roommate drama, and questionable decisions into one entertaining place.

### The Problem (that doesn't exist)

College life has too many small disasters and not enough dramatic dashboards to announce them. Students must track deadlines, empty wallets, and suspicious “K” messages with zero unnecessary technology.

### The Solution (that nobody asked for)

Survival OS turns student chaos into a fun control room. It roasts money habits, watches procrastination, translates risky messages, and gives offline survival advice with a Manglish student vibe.
