# Installation
1.	Download or copy the entire project folder (all the files such as package.json, index.html, the src folder, etc.) onto your computer — for example into a folder like Documents\AeroRoute or Desktop\AeroRoute.

2.	Keep every file together in that one folder. Do not move individual files out — the launcher scripts and configuration files expect to sit next to each other.

3.For the first launch

	1.	Open the project folder in File Explorer
.
	2.	Click once in the empty address bar at the top of the File Explorer window (where the folder path is shown).

	3.	Type cmd and press Enter. This opens a black terminal window already pointed at your project folder — you do not need to type any folder paths yourself.

	4.	In that terminal window, type npm install and press Enter





# Run
Either double click start-aeroroute.bat or launch-aeroroute.vbs OR run  npm run dev  in a terminal
