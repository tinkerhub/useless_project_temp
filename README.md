### Project Description
Spillup is a fun real-time messaging platform that turns ordinary conversations into a playful Gossip Intelligence experience. It provides dual chat windows, gossip monitoring, gossip streaks, reactions, a leaderboard, and entertaining AI-style gossip audits.

### The Problem (that doesn't exist)
People gossip every day, but there is absolutely no proper system to measure it.

Who is gossiping the most?

Who is spilling the hottest tea?

Who deserves the title of Gossip King?

These are clearly problems humanity has been ignoring for far too long. ☕🕵️

### The Solution (that nobody asked for)
Introducing Spillup — a completely unnecessary solution to a problem that nobody asked us to solve.

Spillup monitors conversations in real time and turns gossip into statistics, streaks, rankings and dramatic intelligence reports.

Because apparently, normal messaging was not enough. 😂

### Implementation
**For Software:**

Spillup provides a web-based messaging interface with single and dual conversation views. Users can select identities, enter conversations, send messages, react to messages and view gossip-related information.

The application includes:
- Real-time messaging interface
- Dual chat windows
- Contact selection
- Gossip streak tracking
- Gossip Intelligence Audit
- Gossip Leaderboard
- User reactions
- Guest view mode
- Gossip rank progression

The live application also includes predefined conversation pairs such as Alice ↔ Bob, Carol ↔ David, and Alice ↔ Work Team.

#### Installation
Clone the project repository:
```bash
git clone <your-github-repository-url>
```

Navigate to the project directory:
```bash
cd spillup
```

Install the required dependencies:
```bash
npm install
```

#### Run
Start the development server:
```bash
npm run dev
```

Open the local URL displayed in the terminal.
