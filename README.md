## Project Description

**The Big Belly King** is a funny and completely unnecessary game where the player tries to become the ultimate **Laddu King**! 👑🍬

The player has to complete different silly mini-games, collect laddus, and manage their daily laddu limit. Winning games earns more laddus, while losing can send the player back to the beginning of a level.

---

## The Problem (that doesn't exist)

Have you ever worried that you are not eating enough virtual laddus?

No?

Exactly. 😂

There was absolutely no need for a game to solve this problem — so we made one anyway.

---

## The Solution (that nobody asked for)

Introducing **The Big Belly King** — a useless but fun game where your mission is simple:

> **WIN GAMES. COLLECT LADDUS. BECOME THE BIG BELLY KING. 👑**

The game contains funny mini-games and challenges where players can earn virtual laddus.

Players have a limited number of laddus they can make each day, but they can also earn additional laddus by winning games.

Lose a challenge?

💀 Back to the level!

Win?

🍬 MORE LADDUS!

# Features

## 👑 Running King

A fun running-style mini-game where the player has to survive obstacles and reach the goal.

The player gets a limited number of attempts and needs to perform well to progress.

---

## 🍬 Laddu Chasing

A mini-game where the player has to chase and collect laddus.

Collect as many as possible before the challenge ends!

---

## 🍛 Curry Adi

A silly reaction-based mini-game where the player has to deal with the legendary **Curry Adi**.

Because apparently collecting laddus wasn't useless enough. 😂

---

## 🍬 Daily Laddu System

The player has a daily limit for making/obtaining laddus.

There are two ways to get more:

1. Make laddus using the limited daily allowance.
2. Win mini-games to earn additional laddus.

This creates a simple reward system that encourages players to keep playing.

---

## ❤️ Lives / Attempts

Each game has limited attempts.

Winning helps the player progress.

Losing may cause the player to restart the current level.

---

## 🏆 Level Progression

The player progresses through different levels by completing challenges.

Each level becomes more challenging and more ridiculous.
