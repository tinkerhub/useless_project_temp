### Project Description
Syntax Sighs is a parody code editor designed for the Useless Projects 3.0 Hackathon. Instead of helping you write better code, it actively judges your mistakes and sabotages your self‑esteem.

Whenever you make a typo, forget a semicolon, or trigger a compiler error, the IDE responds with:
* Disappointed sigh sound effects 
* Brightness dimming 
* Comic Sans font punishment 
* Passive‑aggressive pop‑ups reminding you of your “life choices”

### The Problem (that doesn't exist)
Programmers are far too comfortable when making mistakes. Every time they forget a semicolon, misspell a variable, or trigger a compiler error, their IDE politely highlights the issue and waits patiently.

This is unrealistic. In real life, mistakes deserve judgment, sighs, and emotional damage. Without proper shame, developers risk becoming overconfident, happy, and productive — and we simply cannot allow that.

Syntax Sighs solves this non‑existent problem by ensuring every coding error comes with maximum emotional punishment.

### The Solution (that nobody asked for)
Introducing Syntax Sighs — the world’s first IDE that doesn’t just highlight your mistakes, it emotionally reacts to them.

Instead of calmly underlining errors, our editor:
* Audibly sighs every time you mess up 
* Dims your screen brightness to reflect your coding shame 
* Switches your font to Comic Sans as punishment 
* Throws passive‑aggressive pop‑ups reminding you of your “life choices” 

We’ve weaponized your IDE to become your harshest critic, ensuring that every bug feels like a personal failure. Productivity? Zero. Entertainment? Maximum.

## Technical Details
### Technologies/Components Used
For Software:
- JavaScript (frontend interactivity)
  HTML & CSS (UI design & styling)
  Node.js (backend logic, error detection)
- React.js (for building the interactive editor interface)
  Express.js (for lightweight server handling)
- Howler.js (for sigh sound effects)
  FontSwitcher (to swap fonts to Comic Sans)
  Chroma.js (for brightness/dimming effects)
- VS Code (development environment)
  Git & GitHub (version control + collaboration)
  npm (package management)
