Project Description

ALIEN COMPLAINT PORTAL is a futuristic government-style grievance portal designed for extraterrestrials living on Earth.

Aliens can file complaints about humans, WiFi, traffic, food, gravity, weather, and other extremely serious intergalactic problems. The portal lets them submit, search, filter, and track complaints while providing completely questionable customer support.

The Problem (that doesn't exist)

Aliens have apparently been living among humans without access to a proper grievance redressal system.

How are extraterrestrials supposed to complain when:

Earth WiFi is slower than intergalactic travel?
Gravity is unnecessarily strong?
Humans keep asking where they're "really" from?
Earth weather changes every three minutes?
There is no adequate UFO parking?
Humans have incorrectly classified tomatoes?

Clearly, this is a major administrative crisis.

The Solution (that nobody asked for)

We created the ALIEN COMPLAINT PORTAL, an unnecessarily serious government-style complaint management system for aliens.

Extraterrestrials can submit complaints, upload evidence, select how serious their problem is, track their complaint, browse complaints from across the universe, view ridiculous statistics, and even contact the Department of Intergalactic Minor Inconveniences.

Because apparently, even aliens deserve customer support.

Data & Persistence

The application uses localStorage to persist complaints when no backend is available.

This allows:

Complaints to survive page refreshes
Newly submitted complaints to appear in the dashboard
Complaint IDs to remain trackable
Statistics to update based on stored complaints
The application to function without authentication or a database

The data layer is separated from the UI so that a backend API/database can be connected later with minimal changes.

Responsive Design

The application is designed to work across:
