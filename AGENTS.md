# TOO MUCH — Project Rules

This is a React + Vite egg decorating game.

Rules:
- Do not introduce unnecessary libraries.
- Keep the game client-side.
- Use CSS for simple animations.
- Use Canvas only for freehand drawing/particles where appropriate.
- Do not rewrite working components unnecessarily.
- Keep components small.
- Do not change the visual design without being asked.
- Do not remove existing functionality.
- Test after every major change.
